# 0.89 — Woodcore annonce ses mises à jour

Publiée le 23.09.2026. Woodcore vous prévient désormais lui-même quand une nouvelle version est publiée, et ce site existe. Rien ne change dans vos rapports.

## Nouveau

- **Les mises à jour sont annoncées.** À chaque démarrage, Woodcore demande à ce site si une version plus récente est publiée. Si oui, une fenêtre la présente avec ses nouveautés :
  - **Installer** télécharge l'installateur, vérifie son empreinte SHA-256 et le lance ;
  - **Plus tard** repose la question le lendemain ;
  - **Ignorer cette version** ne la propose plus — la suivante le sera.
  Sans connexion, rien ne s'affiche. Une version déjà installée n'est pas proposée.
- **Ce site** : la page de téléchargement, un [tutoriel](~/tutorial/), des [exemples](~/examples/), la [référence de toutes les commandes](~/docs/) — celle de l'onglet **Commandes** de Woodcore — et ces pages de nouveautés.

## Ce qui change dans vos rapports

Rien : le moteur Typst de la version 0.89 est celui de la 0.88. Comme son numéro change, Woodcore propose tout de même de mettre à jour le moteur de chaque projet à son ouverture ; **Voir les différences…** le confirme.

## À faire

- **Installez la 0.89.0 à la main, une fois**, depuis la page [Télécharger](~/download/) : les versions précédentes ne savent pas encore annoncer les mises à jour. Les suivantes seront proposées par Woodcore lui-même.
- À l'ouverture de chaque projet, acceptez **Mettre à jour**.
