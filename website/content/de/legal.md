## Prüfung auf Updates

Beim Start liest eine installierte Version von Woodcore die Datei `version.json` auf dieser Website, um festzustellen, ob eine neue Version besteht. Es werden keine Daten Ihrer Projekte übermittelt. Wie bei jeder Internetanfrage erhält der Server, der diese Website beherbergt — Cloudflare —, die IP-Adresse des Computers und kann sie in seinen Protokollen speichern; dasselbe gilt für GitHub, das beim Herunterladen das Installationsprogramm ausliefert. Die Prüfung lässt sich abschalten, indem Sie `"updates": {"enabled": false}` in die Datei `%APPDATA%\Woodcore\settings.json` eintragen.
