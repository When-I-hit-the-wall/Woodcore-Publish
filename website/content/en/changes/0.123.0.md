# 0.123 — The manual selection taken out of the window

## What changes in your reports

- **The «Manual selection» (level of detail −1) has left the window**: the engine no longer knew it since the Typst commands were rebuilt (0.120). What it chose is written in the line's file with the fine display arguments (`display:`, `#calc-defaults`) and `#var-table`.
- **A simple compression and a simple bending no longer print their verdict twice**: the `η_s` line, equal to `η`, was there only for the manual selection. It leaves new domains and the tab's «Results» card, in the fire situation too. Buckling and lateral torsional buckling keep their `η_s`, one verdict among several.

## To do

- Nothing: in your existing projects, the `#eq("eta_s", …)` line already written for a compression or a bending stays, correct and without a warning, but Woodcore no longer keeps it up to date. Delete it by hand if you want the verdict once.
