# 0.90 — Woodcore's window dressed as the website

Woodcore's window takes this site's colours and typography, light or dark. A new project exports without a load workbook, and the update window leads to the pages of what's new. Nothing changes in your reports.

## New

- **Light or dark.** The **File › Appearance** menu offers:
  - **Like Windows**, the default: Woodcore follows Windows' theme, even when it changes while the window is open;
  - **Light** or **Dark**: Woodcore keeps that theme, title bar and dialogs included.
  The choice is remembered for your user.
- **The site's colours and fonts.** One palette serves the site and Woodcore's window. The banners (a project open read-only, a stale export) look like the site's callouts. **Export PDF** and **Open project** are the primary buttons, in teal. Text is set in Segoe UI, code in Cascadia Mono. Subscripts, superscripts and Greek letters show as before.
- **A project without a load workbook exports.** As long as no export has read a `Belastungsannahmen` workbook, its absence is only a warning: the PDF is produced without the snow, wind and permanent loads. The live loads of SIA 261 (Table 8) stay available. A new project therefore exports as soon as it is created.
- **The update window leads to these pages.** Under a version's notes, the link «What changes for you, and what to do» opens its page in the browser.

## What changes in your reports

Nothing: version 0.90's Typst engine is 0.89's, and the figures are unchanged. As the number changes, Woodcore still offers to update each project's engine when it opens; **Show differences…** confirms it.

One case still stops, on purpose: a project whose export **has already read** a load workbook, and that workbook is gone. The export names it rather than print a report without loads and say nothing. To give up the loads of such a project, delete `Statischer Bericht (typst)/_woodcore/data/project.json`: the next export goes on without them.
