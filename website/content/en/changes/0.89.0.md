# 0.89 — Woodcore announces its updates

Published on 23.09.2026. Woodcore now tells you itself when a new version is published, and this site exists. Nothing changes in your reports.

## New

- **Updates are announced.** At every start, Woodcore asks this site whether a newer version is published. If one is, a window presents it with what is new:
  - **Install** downloads the installer, checks its SHA-256 and runs it;
  - **Later** asks again the next day;
  - **Skip this version** does not offer it again — the next one will be.
  Without a connection nothing is shown. A version already installed is not offered.
- **This site**: the download page, a [tutorial](~/tutorial/), [examples](~/examples/), the [reference of every command](~/docs/) — that of Woodcore's **Commands** tab — and these pages of what's new.

## What changes in your reports

Nothing: version 0.89's Typst engine is 0.88's. As its number changes, Woodcore still offers to update each project's engine when it opens; **Show differences…** confirms it.

## To do

- **Install 0.89.0 by hand, once**, from the [Download](~/download/) page: the previous versions cannot announce updates yet. The next ones will be offered by Woodcore itself.
- When each project opens, choose **Update**.
