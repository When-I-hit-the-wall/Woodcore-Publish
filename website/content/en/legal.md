## Update check

At start-up, an installed Woodcore reads the file `version.json` on this website to find out whether a newer version exists. No data from your projects is sent. As with any internet request, the server hosting this website — Cloudflare — receives the computer's IP address and may record it in its logs; so does GitHub, which serves the installer when it is downloaded. The check is turned off by writing `"updates": {"enabled": false}` into the file `%APPDATA%\Woodcore\settings.json`.
