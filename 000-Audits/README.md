# 000-Audits — les rapports de `prompt-audit.md`

Chaque exécution du prompt d'audit (`prompt-audit.md`, à la racine du projet) dépose ici un rapport `AAMMJJ-HHhMM-audit.md`. Le dossier est versionné : chaque audit se compare au précédent (constats nouveaux, résolus, persistants), ce qui suppose que l'historique soit conservé.

Rien ici n'est lu par le pipeline : ni `calc/`, ni `lib/`, ni le rapport Typst.
