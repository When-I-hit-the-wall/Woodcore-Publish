> What each test file of the report's Typst commands guards -- the calculations written by hand, their display, the citations and the bibliography, the summaries, the timber checks and the commands' documentation --, one row a file. Taken out of `testing-catalogue.md` on 2026-10-21 (spec 2026-10-21-commandes-typst-refonte), that file having reached 100 KB; the rows were moved verbatim.
