# Tests: the catalogue

> What each file of `tests/` guards, one row a file. Moved verbatim from `testing.md` (§11ter) on 2026-10-10 (issue #31), the file having reached 135 KB; how to run the tests stays there. The rows are in two files by one mechanical rule: a row that names §10quater or a window built off-screen is in [`testing-catalogue-window.md`](testing-catalogue-window.md), every other row here. Not generated from the test files' docstrings: a row says why a file exists and what it caught, which a docstring does not always; `tests/test_docs_coherence.py` holds every `tests/test_*.py` to a row of one of the two. The rows the table lacked that day -- thirty files, among them the audit's -- were written then from each file's docstring and its count of checks.
