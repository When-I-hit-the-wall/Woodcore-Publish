# Tests: the catalogue of the repository's guards

> What each file of `tests/` that guards the repository as a whole guards -- the runner and the CI, the documentation, the size and the duplicates of the code, its line endings, the figures held to the byte, the names it may not hold --, one row a file. Moved verbatim from `testing-catalogue.md` on 2026-10-19, when that file reached the 100 KB every file of `docs/` stays under (`tests/test_docs_coherence.py`).
