## 10quater (suite) — python tab

**The Python tab (v0.100).** *Python* (group *Projet*, after *Journal*; `calc/tools/python_tab.py`, its words under `py_`) is where the engineer writes Python, runs it and reads the values his variables took — «afin de ne pas avoir à lire le terminal», which is why the right pane carries three cards: the **Résultats** the script declared, the **Variables** its globals held when it ended (a numpy array with its shape, a scalar with its value), and the **Sortie** it printed. On the left the project's scripts, grouped by their `@group` (the `GroupedList` every editor tab has, showing its folders and taking no drop — what *Moments polaires* did from v0.69 to v0.74), with *Nouveau*, *Dupliquer*, *Renommer* and *Supprimer*; in the middle the identity read from the file, an editor coloured with the site's own syntax tokens (`PythonHighlighter`, the tokens `richtext.TypstHighlighter` colours Typst with), and *Exécuter*, which saves, runs in a process of its own and exports — so what ran is what is on disk, which is what the export will run. ⚠️ **The identity is read-only**, three `@` comment lines in the file itself, which is the one place a tab of this window does not offer Nom · Description · ID as a form, and deliberately (§13). A new script starts from a template that solves a system and declares two results, so the first thing seen is a script that runs. A project opened read-only refuses its *Enregistrer* and *Supprimer* (`WRITERS`).
