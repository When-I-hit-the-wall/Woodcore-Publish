## 10quater (suite) — commands tab

**The commands tab (v0.64).** *Commandes / Befehle / Commands*, the last tab, lists every command the project defines — in categories, with its arguments, two calls to copy and its worked examples, each rendered by compiling it. It is described in **§10sexies**, apart from the tabs above it, because it documents the engine's own surface rather than this project's data: its modules are `calc/tools/commands_tab.py` and `calc/tools/command_preview.py`.
